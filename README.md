# Divyanshi Aviation Services Pvt Ltd

Official web portal and platform for Divyanshi Aviation Services Pvt Ltd — Specialists in Temperature Controlled Packaging, Cold Chain Logistics, and Aerospace Consumables.

## Project Structure

- `src/` — React frontend built with Vite, TypeScript, and Tailwind CSS.
- `backend/` — Express.js REST API with TypeScript, PostgreSQL, and Cloudinary.
- `public/` — Static assets and media.

## Getting Started

### Frontend

```bash
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run dev
```
